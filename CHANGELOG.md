# Changelog

Notable changes to `aisdk/concentrate`. Release notes are also published at https://github.com/phpaisdk/concentrate/releases.

## v0.11.0 — 2026-10-31

- Requires `aisdk/core ^0.11.0` and `aisdk/openai-compatible ^0.11.0`. Upgrade SDK packages together; no other changes in this package.

- Tools, structured output, reasoning and image inputs where the selected model supports them.

### Compatibility

- Requires `aisdk/core ^0.10.0` and `aisdk/openai-compatible ^0.10.0`.
